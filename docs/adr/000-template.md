# ADR NNN — Título

- **Estado:** Propuesto | Aceptado | Reemplazado por ADR XXX
- **Fecha:** AAAA-MM-DD
- **Reemplaza a:** ADR XXX (solo si corresponde)

> Una vez aceptado, un ADR no se edita. Para cambiar una decisión se crea un ADR nuevo que lo reemplaza, y en este solo se actualiza el campo *Estado*.

## Contexto
Qué problema o necesidad motiva la decisión, y qué restricciones hay (enunciado, tiempo, entorno).

## Decisión
Qué se decidió, de forma concreta.

## Alternativas consideradas
- **Alternativa A:** en qué consiste y por qué se descartó.

## Consecuencias
- Positivas, negativas y lo que queda abierto a futuro.
